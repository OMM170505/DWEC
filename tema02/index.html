Navegadores y motores

Navegador Empresa Motor de renderizado Motor de JavaScript ¿Basado en Chromium?

Safari Apple WebKit JavaScriptCore No
Edge Microsoft Blink V8 Sí
Opera Opera Software Blink V8 Sí

La mayoria de los navegadores actuales comparten el motor Chromium, porque ofrece una buena compatibilidad con las tecnologias web actuales. Chrome, Edge y Opera incorpora sus propias caracteristicas. Firefox utiliza Gecko y Safari WebKit. Para un desarrollador esto significa que puede verse o funcionar de manera ligeramente diferente segun el navegador, por eso es importante probar una pagina web en diferentes navegadores y tambien moviles.
