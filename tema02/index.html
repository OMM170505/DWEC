La mayoria de los navegadores actuales comparten el motor Chromium, porque es de codigo abierto ycuenta con el trabajo y mantenimiento de muchas personas y empresas. Para una empresa es mas practico utilizar un motor que ya existe, que crear y mantener uno propio desde cero, lo que supondria mas tiempo y recursos. Chrome, Edge y Opera utilizan Chromium, mientras que Firefox utiliza Gecko desarrollado por Mozilla y Safari usa WebKit desarrollado por Apple. Safari es especialmente importante en Iphone y Ipad. Para un desarrollador, esto significa que una web puede funcionar de manera diferente segun cada navegador. Si solo se prueba Chrome pueden aparecer errores de diseño o funcionalidad en otros navegadores. Por eso es importante probar la web en varios navegadores y dispositivos, para asegurar que todos los usuarios tengan una buena experiencia.
